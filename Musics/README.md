# Musics

The owner's music for Klyp videos. When this folder holds audio files, the
klyp-reel skill uses only these tracks (the release library music is ignored).

- Drop any audio file here (mp3, wav, m4a, ogg, flac). Subfolders named after a
  mood (upbeat, chill, lofi, pulse) or a "mood - Title.mp3" file name set its mood.
- Describe a track in tracks.json (title, artist, mood, license, source, credit).
  Without an entry the skill assumes you cleared it yourself and adds no credit.
- Licences NC or ND are refused. CC BY needs a credit line, the skill adds it to
  the captions.
